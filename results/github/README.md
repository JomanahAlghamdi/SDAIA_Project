# GitHub execution records

Earlier JSON files retain the exact attempts and source commits they name, including historical missing-secret failures. They are not the current setup or submission status. The repository secret was present and working during the English-chat evaluations.

Use [current run status](../current_run_status.json), [technical readiness](../requirements_status.json), [error analysis](../../docs/error_analysis.md), and the workflow links recorded with the final review. An Actions job succeeding means its commands completed; the actual CSVs and transcripts determine task outcomes.
